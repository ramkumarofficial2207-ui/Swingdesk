# Security policy

Please do not open a public issue for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it, and its impact. You will get a reply within 7 days.

In scope: the API, authentication, broker-token handling, and anything that could place or alter orders or expose user data.

If you find a committed secret, report it the same way; it will be rotated, not just deleted.
